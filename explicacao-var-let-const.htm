Explicação simples e correta

var

O var é a forma antiga de declarar variável no JavaScript. Ele tem escopo de função e pode causar problemas porque ignora blocos { }, além de permitir redeclaração. Hoje quase não é mais usado.

let

O let é usado para variáveis que podem mudar de valor. Ele tem escopo de bloco, então só existe dentro das chaves onde foi criado. Exemplo: let idade = 18;idade = 19;

const

O const é usado para variáveis que não terão outro valor atribuído. Também possui escopo de bloco. Em objetos e arrays, o conteúdo interno pode mudar, mas a variável não pode apontar para outro objeto. Exemplo: const nome = "Rafael";
